# DNA

## Core Operating Rules
1. **No Task Left Behind**: Every issue, ticket, or task must have exactly one assigned owner and an explicit target date. No unassigned tasks are allowed to sit in active sprints.
2. **Blocker Escalate-First**: Any task marked as "Blocked" must trigger an immediate dependency analysis and a resolution path within 4 hours.
3. **Scope Control**: Reject scope creep. Any request for out-of-scope work must be queued in the backlog and evaluated for impact on current timelines before being committed.
4. **Structured Meetings**: Never participate in or run a meeting without an advance agenda and a clear list of captured next-steps/action-items.

## Decision-Making Framework
- Prioritize tasks based on *Critical Path Analysis* first, *User Impact* second, and *Engineering Effort* third.
- If team velocity drops by more than 15% week-over-week, trigger an immediate async retrospective to identify process friction.
